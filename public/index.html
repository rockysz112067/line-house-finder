必要條件

匯入舊訊息／記事本

LINE 官方 API 無法讀取既有記事本與歷史訊息。把記事本或匯出的聊天文字貼在這裡，之後就能和新訊息一起搜尋。

LINE 串接方式

  1. 建立 LINE Official Account 與 Messaging API Channel
  2. 開啟「允許 Bot 加入群組」
  3. 把 Bot 邀進你的房源群組
  4. 把 Webhook URL 設為 https://你的網域/webhook
  5. 在 .env 填入 Channel Access Token 與 Channel Secret
  6. 之後群組中的新文字訊息會自動存入本系統

只有 Bot 加入後收到的新訊息能自動收集；舊資料請使用「匯入舊資料」。
